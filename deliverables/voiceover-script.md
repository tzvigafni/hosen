# תסריט הקראה לסרטון התדמית של דַּבֵּר (17.5 שניות)

קצב: רגוע וחם, כ-2.5 מילים בשנייה. כל שורה מתחילה בזמן שמצוין לידה.

| זמן | מה רואים | טקסט להקראה |
|---|---|---|
| 0.3–3.0 | הלוגו | "דַּבֵּר. אנגלית שמדברים." |
| 3.3–6.2 | "רוצים לדבר אנגלית בביטחון?" | "רוצים לדבר אנגלית בביטחון? בעבודה, בנסיעות, עם הילדים?" |
| 6.6–9.9 | מסך שיעור | "שיעורים מסודרים לפי רמות, עם הסברים בעברית ותרגול בכל שיעור." |
| 10.3–13.6 | שיחה עם דניאל | "ואז מדברים באמת: שיחה קולית עם מורה וירטואלי." |
| 14.0–17.2 | רשימה וסיום | "חזרה חכמה, תזכורות, ומתאים לגלישה מסוננת. דַּבֵּר – בקרוב." |

## איך מקליטים
- הכי פשוט: מקליטים בטלפון, שורה אחרי שורה, בחדר שקט, ושולחים לי את הקבצים. אני מסנכרן למסכים ומנמיך את המוזיקה מתחת לקול.
- הקראה ב-AI: שולחים לי מפתח API לשירות הקראה שתומך בעברית (למשל Google Cloud Text-to-Speech או ElevenLabs), ואני מפיק את ההקראה ומשלב אותה.
